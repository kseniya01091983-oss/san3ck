# Состояние проекта FastNotes

## Назначение

FastNotes сохраняет личные заметки, ссылки, рекомендации, изображения и файлы через Telegram и позволяет просматривать и искать их на сайте.

## Текущее устройство

- Исходная версия работает на Python и aiogram в режиме polling.
- Данные хранятся в локальной SQLite-базе `notes.db`.
- Локальный aiohttp-сервер обслуживает REST API, SSE и сайт `site/index.html`.
- AI-обработка поддерживает Groq, Gemini, OpenRouter и локальный резервный алгоритм.
- Реализованы создание, список, просмотр, редактирование, скрытие, публикация и удаление заметок.
- Сайт FastNotes имеет светлую, тёмную и автоматическую темы, поиск, фильтры и разделы.

## Целевая версия

- Telegram webhook и серверная логика: Cloudflare Worker на TypeScript.
- База заметок и метаданных: Cloudflare D1.
- Изображения и документы: описание и Telegram `file_id` в D1; R2 не используется.
- Обработка текста и изображений: OpenRouter.
- Извлечение содержимого ссылок: Tavily Extract.
- Существующий сайт: Worker Static Assets и защищённый API.

## Основные файлы

- `main.py`, `bot/` — исходный Python-бот.
- `site/index.html` — интерфейс FastNotes.
- `notes.db` — исходная база и резервная копия.
- `worker/src/` — новая облачная реализация.
- `worker/migrations/` — схема D1 и полнотекстовый поиск.
- `worker/scripts/export_sqlite_to_d1.py` — безопасный экспорт SQLite в D1 SQL.
- `worker/test/` — модульные и интеграционные тесты Worker.

## Важные решения

- Сервис будет однопользовательским.
- Внешний вид FastNotes сохраняется.
- Python-версия остаётся в репозитории как исходная работа Саши.
- Сайт получает временную ссылку из Telegram и защищённую cookie-сессию.
- Вместо SSE сайт обновляет данные из D1 раз в пять секунд.
- Одна модель текста и изображений: `z-ai/glm-5.3-flash`. Разрешены только DeepInfra, Novita, Z.AI и GMICloud; затем отдельный резерв DeepSeek и бесплатный маршрут.
- От R2 отказались по просьбе владельца: D1 хранит Telegram `file_id`, а Worker временно получает файл из Telegram для анализа или защищённой выдачи сайту.

## Известные ограничения

- Полный пользовательский сквозной сценарий с сообщениями из приложения Telegram рекомендуется дополнительно пройти вручную.
- Очищенная ветка `cloudflare-migration` опубликована в `kseniya01091983-oss/san3ck`. Её Git-история не содержит `notes.db`.
- Реальные интеграционные проверки Telegram, OpenRouter и Tavily потребуют ключей владельца.

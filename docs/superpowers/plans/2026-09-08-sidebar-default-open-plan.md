# План реализации панели разделов

1. Убрать сохранение состояния панели в `localStorage`.
2. Открывать панель при ширине от `1024px`, закрывать на меньшей ширине.
3. Сохранить существующие кнопки, фон и клавиатурные команды.
4. Синхронизировать `aria-expanded` и недоступность скрытой панели для клавиатуры.
5. Исключить анимацию первоначального появления, сохранив анимацию пользовательского переключения.
6. Проверить синтаксис сайта, адаптивное поведение и тесты Worker.
7. Обновить `PROJECT_STATUS.md`, развернуть Worker и отправить изменения в `cloudflare-migration`.

# План реализации отдельного доступа преподавателя

1. Добавить единый модуль проверки владельца и преподавателя.
2. Добавить `TEACHER_TELEGRAM_ID=126041348` в конфигурацию Worker.
3. Передавать ID действующего пользователя во все Telegram-операции с D1.
4. Подписывать ссылку `/site` и cookie для конкретного Telegram ID.
5. Передавать ID сайт-сессии в API и фильтровать по нему все CRUD-запросы.
6. Добавить тесты доступа и взаимной невидимости заметок.
7. Обновить русскую документацию, выполнить typecheck и тесты.
8. Развернуть Worker и опубликовать безопасный коммит в `cloudflare-migration`.

# План уведомлений Telegram об обработке

1. Расширить обёртку Telegram API: возвращать `message_id` после отправки и поддержать `editMessageText`.
2. После записи исходника в D1 немедленно показать подтверждение «сохранено, обрабатываю».
3. По завершении заменить подтверждение готовой карточкой или явным сообщением об ошибке с кнопкой повтора.
4. Добавить атомарный захват повторной обработки, чтобы двойное нажатие не создавало параллельные AI-запросы.
5. Покрыть успешный и ошибочный сценарии тестами, обновить документацию, выполнить typecheck, Vitest и сухую сборку Wrangler.
6. После проверки развернуть Worker и безопасно опубликовать изменения только в ветку `cloudflare-migration` пользовательского репозитория.

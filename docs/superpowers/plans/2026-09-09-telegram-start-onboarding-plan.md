# План реализации приветствия FastNotes после Start

1. Расширить текст `/start` короткими примерами фильма, задачи, ссылки, изображения и вопроса `/ask`.
2. Оставить предупреждение: задачи сохраняются, но напоминания по времени пока не отправляются.
3. Показать четыре кнопки: заметки, сайт, вопрос и полная справка.
4. Добавить обработчик кнопки полной справки, использующий существующий текст `/help`.
5. Дополнить тесты: текст, четыре кнопки, полная справка, отсутствие AI/Tavily и новых заметок при `/start`.
6. Обновить русскую документацию проекта.
7. Запустить TypeScript-проверку, Vitest и пробную сборку Wrangler.
8. Развернуть Worker, проверить `/health` и опубликовать очищенную ветку `cloudflare-migration` без базы и секретов.

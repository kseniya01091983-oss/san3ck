# План реализации десяти улучшений FastNotes

## Этап 1. Telegram

1. Добавить типы и вызов Telegram `setMyCommands`.
2. Разделить короткое приветствие `/start` и подробную справку `/help`.
3. Добавить кнопки списка, сайта и подсказки по вопросам.
4. Добавить `/cancel` с очисткой состояния конкретного пользователя.
5. Покрыть команды, кнопки и изоляцию тестами.

## Этап 2. Сайт

1. Расширить локальный поиск на заголовок и краткое описание.
2. Добавить строку количества результатов и общий сброс фильтров.
3. Показать `Открыть источник` в карточке и подробном окне ссылки.
4. Добавить выход через существующий `POST /auth/logout`.
5. Сохранить текущие темы, адаптивность и ручное обновление.

## Этап 3. Проверка и выпуск

1. Проверить статусы ошибок и исправленные подсказки.
2. Проверить синтаксис HTML/JavaScript, TypeScript, Vitest и сухую сборку Wrangler.
3. Обновить `PROJECT_STATUS.md` и `worker/README.md`.
4. Развернуть существующий Worker после успешных проверок.
5. Опубликовать безопасное дерево файлов только в `cloudflare-migration` репозитория Ксении; не включать `notes.db`, секреты и локальные данные Wrangler.

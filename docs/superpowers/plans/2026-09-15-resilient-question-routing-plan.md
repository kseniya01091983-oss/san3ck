# План устойчивой обработки вопросов

1. Добавить и протестировать локальное определение естественного вопроса и подготовку поисковой фразы для D1.
2. Передавать распознанные вопросы в OpenRouter с обязательным намерением `answer_question`.
3. Добавить безопасный резервный ответ из найденных записей D1 при временной ошибке OpenRouter.
4. Вынести общую обработку текстовой записи и использовать её как при новом сообщении, так и при ручном повторе.
5. Перераспределить ограниченные таймауты маршрутов OpenRouter без изменения списка и порядка провайдеров.
6. Обновить справку Telegram и `PROJECT_STATUS.md`.
7. Запустить typecheck, Vitest и Wrangler dry-run; затем после проверки развернуть Worker и опубликовать очищенную ветку.

# План реализации приветствия преподавателя

1. Добавить в Telegram API настройку описания и короткого описания бота.
2. При `/start` сохранить прежнее приветствие владельца, а преподавателю показать короткие четыре шага проверки домашнего задания.
3. Добавить кнопку ручной подготовки смыслового индекса, использующую существующую изолированную переиндексацию пользователя.
4. Покрыть оба приветствия и callback переиндексации тестами.
5. Обновить русскую документацию, выполнить typecheck и Vitest.
6. Развернуть Worker и проверить `/health`.

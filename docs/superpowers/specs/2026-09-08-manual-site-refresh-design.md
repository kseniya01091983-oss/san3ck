# FastNotes: ручное обновление сайта

## Цель

Полностью убрать постоянный опрос Worker и D1 из открытого сайта. Сайт должен расходовать лимиты только при открытии страницы, при явном нажатии пользователем кнопки и при обычных операциях создания, изменения или удаления.

## Поведение

- При первом открытии сайт один раз загружает заметки из `/api/notes`.
- Таймер `setInterval(fetchNotes, 5000)` удаляется.
- В верхней панели рядом с существующими действиями появляется кнопка `Обновить` в стиле текущего интерфейса.
- Кнопка вручную вызывает `fetchNotes()` и на время запроса блокируется, чтобы двойное нажатие не создавало несколько запросов.
- Если данные не изменились, карточки повторно не создаются и их анимации не запускаются.
- После успешной проверки показывается понятное уведомление; при ошибке прежние карточки остаются на экране.
- При скрытой вкладке, возвращении на неё и простом ожидании запросы не выполняются.
- Создание, редактирование, скрытие и удаление через сам сайт продолжают сразу обновлять локальный интерфейс.

## Расход лимитов

Без действий пользователя открытая вкладка не расходует Worker-запросы и чтения D1. Один запрос выполняется при открытии сайта и один — на каждое нажатие `Обновить`. Отправленная через Telegram заметка появится на уже открытом сайте только после ручного обновления.

## Проверка

- В коде сайта отсутствует периодический вызов `fetchNotes`.
- После открытия выполняется одна загрузка заметок.
- Ожидание дольше пяти секунд не меняет карточки и не создаёт сетевые запросы.
- Одно нажатие `Обновить` выполняет одну загрузку.
- При неизменных данных карточки не дёргаются.
- Новая запись из Telegram появляется после ручного обновления.

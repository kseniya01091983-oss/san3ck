# Панель разделов, открытая по умолчанию

## Цель

Сделать разделы заметок сразу видимыми на большом экране, сохранив возможность быстро освободить место для карточек.

## Поведение

- При открытии сайта на экране шириной от `1024px` боковая панель сразу открыта.
- Существующая кнопка панели в верхней строке скрывает её и повторно открывает.
- Кнопка закрытия внутри панели продолжает работать.
- Скрытое состояние не сохраняется после перезагрузки: при следующем открытии на компьютере панель снова видна.
- На экранах уже `1024px` панель при открытии сайта закрыта, чтобы не перекрывать содержимое. Она открывается существующей кнопкой как выдвижная панель с затемнением фона.
- При переходе окна с мобильной ширины на компьютерную панель открывается; при переходе обратно закрывается.

## Ограничения изменений

- Сохраняются разметка, размеры, цвета, анимация, темы и иконки Сашиного интерфейса.
- Удаляется только запоминание состояния панели в `localStorage`.
- Логика не выполняет сетевых запросов и не расходует Worker, D1, OpenRouter или Tavily.

## Проверка

- Компьютерная ширина: панель видна сразу, обе кнопки закрытия и открытия работают.
- Мобильная ширина: панель изначально скрыта, открывается поверх страницы и закрывается кнопкой, фоном или после выбора раздела.
- Перезагрузка компьютерной страницы снова показывает панель.
- Переключение ширины через границу `1024px` приводит панель в безопасное состояние для соответствующего экрана.
- JavaScript страницы проходит синтаксическую проверку; тесты Worker остаются успешными.

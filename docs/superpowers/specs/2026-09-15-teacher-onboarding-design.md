# Короткое знакомство преподавателя с FastNotes

## Цель

После первого нажатия **Start** преподаватель должен без объяснений владельца понять, как минимально проверить вторую часть домашнего задания: RAG через Upstash Vector, интеграцию TMDB, отдельную базу заметок и сайт FastNotes.

## Поведение

- Бот не может написать человеку первым до его действия — это ограничение Telegram.
- В профиле и пустом чате бота показывается короткая подсказка: «Нажмите Start / Запустить — бот сразу покажет, как проверить домашнее задание».
- При переходе по ссылке Telegram показывает встроенную кнопку **Start / Запустить**. Преподавателю не требуется вручную печатать `/start`: нажатие кнопки само запускает этот сценарий.
- Worker определяет преподавателя по уже настроенному `TEACHER_TELEGRAM_ID`.
- Владелец продолжает получать прежнее приветствие без изменений.
- Преподаватель по `/start` получает короткую инструкцию из четырёх действий:
  1. нажать кнопку подготовки смыслового поиска;
  2. спросить: «Посоветуй исторический сериал?»;
  3. написать: «Хочу посмотреть Интерстеллар» и сохранить найденную карточку;
  4. открыть сайт и увидеть свои заметки.
- Приветствие прямо сообщает, что заметки преподавателя находятся в отдельном пространстве и не видны владельцу.

## Кнопки преподавателя

- `🧠 Подготовить смысловой поиск` — вручную запускает существующую переиндексацию Upstash для пространства преподавателя.
- `🌐 Открыть сайт` — использует существующую подписанную ссылку на сайт.
- `📝 Мои заметки` — открывает существующий список заметок.
- `📖 Краткая справка` — показывает существующую справку.

## Технические изменения

- Добавить отдельный текст и клавиатуру преподавателя в `worker/src/telegram.ts`.
- В существующей функции `/start` выбирать вариант приветствия по Telegram ID.
- При настройке Telegram автоматически установить общие `description` и `short_description` через Bot API, чтобы подсказка была видна ещё до первого запуска.
- Добавить обработчик callback-кнопки переиндексации, используя существующую `reindexOwner` и существующие безопасные сообщения об ошибках.
- Не добавлять cron, автоматическую переиндексацию и новые внешние запросы без действия пользователя.
- Не менять схему D1, сайт, Python-версию и данные заметок.

## Ошибки и сообщения

- Во время запуска показывать короткое сообщение «Подготавливаю смысловой поиск…».
- При успехе показывать число подготовленных заметок.
- При ошибке использовать существующее безопасное объяснение; обычный поиск D1 продолжает работать.

## Проверка

- Владелец по `/start` получает прежний текст и четыре прежние кнопки.
- Преподаватель по `/start` получает короткий учебный сценарий и четыре предусмотренные кнопки.
- Кнопка подготовки запускает переиндексацию только namespace преподавателя.
- Ссылка сайта открывает только пространство преподавателя.
- Тесты подтверждают отсутствие изменений в заметках владельца и отсутствие автоматических вызовов Upstash.

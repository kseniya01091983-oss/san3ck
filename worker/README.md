# FastNotes на Cloudflare

Это облачная версия Сашиного FastNotes. Оригинальный Python-бот и локальная `notes.db` остаются без изменений. Новый Worker принимает Telegram webhook, хранит заметки и метаданные вложений в D1 и отдаёт прежний сайт из папки `site/`. R2 не нужен.

## Что уже умеет Worker

- принимает текст, ссылки, изображения и обычные файлы из Telegram;
- сразу подтверждает сохранение исходника, а после обработки обновляет сообщение результатом или показывает ошибку с кнопкой ручного повтора;
- сохраняет исходник до обращения к внешним AI-сервисам;
- сразу показывает исходную запись; AI обогащает её после сохранения и не может навсегда спрятать её в черновиках;
- структурирует текст и отвечает по заметкам через OpenRouter;
- объединяет смысловой поиск Upstash Vector с FTS5-поиском D1; при сбое Upstash незаметно использует только D1;
- принимает фразы вроде `Хочу посмотреть Интерстеллар`, ищет фильм или сериал в TMDB, показывает карточку и сохраняет её только после подтверждения;
- извлекает страницу по ссылке через Tavily, но не сохраняет полный текст страницы;
- хранит описание, Telegram `file_id` и метаданные вложений в D1; сами файлы остаются в Telegram;
- поддерживает список, поиск, просмотр, изменение, скрытие, публикацию и удаление;
- показывает после `/start` короткую инструкцию с примерами и четырьмя кнопками, меню команд, подробную `/help` и поддерживает `/cancel`;
- преподавателю показывает отдельный короткий сценарий проверки RAG, TMDB и сайта; кнопку подготовки смыслового поиска можно нажать без ввода `/reindex`;
- не создаёт дубль при повторной доставке одного Telegram update;
- разрешает доступ владельцу из `OWNER_TELEGRAM_ID` и преподавателю `126041348`, сохраняя их заметки раздельно;
- открывает сайт по временной ссылке `/site` и защищает API cookie-сессией.
- не опрашивает базу в фоне: сайт загружает заметки при открытии и затем только по кнопке `Обновить`.
- ищет на сайте по заголовку, описанию, тексту и тегам, показывает число результатов, источник ссылки и кнопку выхода.
- показывает постеры и сведения TMDB в прежнем дизайне сайта; браузер не получает токены и не обращается к API TMDB или Upstash.

## Где расходуются лимиты

Постоянных таймеров, Cron-задач, SSE и фонового опроса в облачной версии нет.

- При открытии сайта выполняется запрос страницы к Worker и одна загрузка списка из D1.
- Кнопка `Обновить` выполняет одну загрузку списка из D1. Без нажатия повторных запросов нет.
- Во время ручной загрузки Worker помечает `pending` старше двух минут как ошибку и сохраняет запись видимой. Запись в D1 выполняется только при наличии такой зависшей заметки.
- Создание, изменение, скрытие и удаление на сайте расходуют по одному пользовательскому API-запросу и соответствующие операции D1.
- Каждое сообщение или нажатие кнопки в Telegram создаёт один webhook-запрос Worker. Повторная доставка одного Telegram update не создаёт вторую заметку.
- `/start` настраивает меню и две короткие подписи профиля Telegram. Эти служебные вызовы не используют OpenRouter, Tavily, Upstash или D1 и не запускаются по таймеру.
- Бот не повторяет AI-обработку по таймеру. Кнопка `Повторить` запускает ровно одну попытку, а двойное нажатие не создаёт параллельные запросы. Для обычного текста повтор заново определяет, был ли это вопрос, фильм/сериал или заметка.
- Обычный текст после сообщения пользователя вызывает поиск D1 и один цикл обработки OpenRouter.
- После подключения Upstash обычный текст или `/ask` выполняет один смысловой поиск. Готовая новая/изменённая заметка выполняет один upsert, только если заголовок, описание или теги изменились.
- Ручная команда `/reindex` отправляет заметки последовательными порциями не более 10 записей и ждёт каждую порцию до 20 секунд. Это не фоновая задача и не запускается без команды пользователя.
- Сетевой сбой предварительного очищения namespace не блокирует повторную загрузку: найденные Upstash ID всё равно проверяются по D1. Значения URL и Token очищаются от случайных пробелов и парных кавычек, а сообщение различает ошибку URL, Token, таймаут и неверную конфигурацию индекса.
- Скрытие и удаление заметки выполняет одно удаление вектора. `/reindex` расходует один сброс namespace и один пакетный upsert и запускается только вручную.
- Фраза о конкретном фильме/сериале выполняет один поиск TMDB. Подробности запрашиваются один раз после однозначного результата или выбора пользователя и сохраняются на 30 минут до подтверждения.
- На сайте TMDB и Upstash по таймеру не вызываются.
- Ссылка после сообщения пользователя вызывает Tavily Extract и OpenRouter. Самостоятельно Tavily не запускается.
- Изображение после сообщения пользователя временно загружается из Telegram и передаётся OpenRouter. Самостоятельно обработка изображений не запускается.
- Естественный вопрос со знаком `?` или словами «посоветуй», «подскажи» и похожими, а также команда `/ask`, вызывают поиск D1/Upstash и OpenRouter только по действию пользователя. При временном сбое OpenRouter бот показывает найденные записи D1 и не сохраняет вопрос как failed-заметку.
- Открытие вложения на сайте вызывает Worker и Telegram Bot API только в момент открытия файла.
- При недоступности выбранного провайдера GLM OpenRouter может попробовать следующие разрешённые маршруты, затем резервную модель. Это происходит внутри обработки одного пользовательского сообщения, а не по таймеру.

## Что находится в папке

- `src/` — код Worker, Telegram, API, OpenRouter, Tavily, Upstash и TMDB;
- `migrations/` — таблицы D1, отказ от R2, индексы и FTS5-поиск;
- `scripts/export_sqlite_to_d1.py` — экспорт старой SQLite-базы только для чтения;
- `test/` — модульные и интеграционные тесты;
- `wrangler.jsonc` — bindings D1 и Static Assets;
- `.dev.vars.example` — пример локальных секретов без настоящих значений.

## Локальная проверка

Нужны Node.js и Python 3. В PowerShell:

```powershell
cd worker
npm install
npm run typecheck
npm test
npm run db:migrate:local
Copy-Item .dev.vars.example .dev.vars
npm run dev
```

Перед `npm run dev` замените примеры в `.dev.vars` своими тестовыми значениями. Этот файл исключён из Git.

## Подготовка Cloudflare

Эти команды выполняются один раз после входа в Cloudflare:

```powershell
cd worker
npx wrangler login
npx wrangler d1 create fastnotes-db
```

Команда создания D1 покажет `database_id`. Вставьте его вместо нулевого ID в `wrangler.jsonc`. В этом же файле задайте:

- `PUBLIC_BASE_URL` — адрес Worker после первого развёртывания;
- `TEACHER_TELEGRAM_ID` — Telegram ID преподавателя; в готовой конфигурации уже указано `126041348`.

Одна модель текста и изображений уже указана в конфигурации: `z-ai/glm-5.3-flash`. Она вызывается только через DeepInfra, Novita, Z.AI и GMICloud. Затем Worker пробует DeepSeek для текста и бесплатный маршрут OpenRouter.

Секреты вводятся интерактивно. Их нельзя записывать в `wrangler.jsonc`:

```powershell
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_WEBHOOK_SECRET
npx wrangler secret put OPENROUTER_API_KEY
npx wrangler secret put TAVILY_API_KEY
npx wrangler secret put SITE_AUTH_SECRET
npx wrangler secret put OWNER_TELEGRAM_ID
```

Для `TELEGRAM_WEBHOOK_SECRET` и `SITE_AUTH_SECRET` используйте две разные длинные случайные строки.

## Подключение RAG и TMDB

В Upstash создайте индекс `fastnotes-rag` со следующими параметрами:

- регион Ireland;
- тип `HYBRID`;
- Dense model: `openai/text-embedding-3-small`;
- Sparse model: `BM25`;
- similarity `cosine`.

Не выбирайте `Custom`: текущий Worker отправляет в Upstash короткий текст через `upsert-data` и `query-data`, а встроенные модели Upstash сами создают dense- и sparse-векторы. При `Custom` пришлось бы отдельно получать оба вида векторов и менять код. `BM25` слабее работает с русской морфологией, поэтому точный русский поиск дополнительно и независимо выполняется через FTS5 в D1.

В TMDB создайте Application Read Access Token. OAuth пользователя не нужен. Затем из папки `worker` запустите:

```powershell
pnpm run setup:integrations
```

Wrangler по очереди попросит `UPSTASH_VECTOR_REST_URL`, `UPSTASH_VECTOR_REST_TOKEN` и `TMDB_READ_ACCESS_TOKEN`. Вставляйте каждое значение прямо в терминал и нажимайте Enter. Ввод не показывается на экране и не записывается в файлы проекта.

После развёртывания один раз отправьте боту скрытую служебную команду `/reindex`. Она пересоберёт только ваш namespace. Преподаватель делает то же самое своей кнопкой `🧠 Подготовить смысловой поиск` в приветствии.

Если терминал неудобен, можно запустить локальную страницу:

```powershell
pnpm run setup:secrets
```

Откройте `http://127.0.0.1:8790`, вставьте токен Telegram и ключи OpenRouter/Tavily и нажмите одну кнопку. Помощник передаёт значения напрямую в Cloudflare Worker Secrets, сам создаёт секрет webhook, регистрирует webhook и устанавливает подсказку перед первым запуском Telegram-бота. Значения не записываются в файл и не выводятся на экран.

## Перенос `notes.db`

Сначала примените схему в облачной D1:

```powershell
npm run db:migrate:remote
```

Затем создайте временный экспорт. Подставьте только свой числовой Telegram ID:

```powershell
python scripts/export_sqlite_to_d1.py --owner-id 123456789
npx wrangler d1 execute DB --remote --file=.data/legacy-notes.sql
```

Скрипт открывает `../notes.db` в режиме только для чтения. SQL-файл содержит личные данные, лежит в исключённой из Git папке `.data` и не должен никому отправляться.

Проверка количества без вывода текста заметок:

```powershell
npx wrangler d1 execute DB --remote --command "SELECT COUNT(*) AS notes_count FROM notes; SELECT COUNT(*) AS search_count FROM notes_fts;"
```

## Развёртывание и Telegram webhook

Первое развёртывание:

```powershell
npx wrangler deploy
```

Wrangler покажет адрес вида `https://fastnotes-second-brain.<поддомен>.workers.dev`. Запишите его в `PUBLIC_BASE_URL` внутри `wrangler.jsonc` и выполните `npx wrangler deploy` ещё раз.

После этого зарегистрируйте webhook методом Telegram `setWebhook`:

- URL: `<PUBLIC_BASE_URL>/telegram/webhook`;
- `secret_token`: та же строка, которую вы ввели как `TELEGRAM_WEBHOOK_SECRET`.

Токен бота и секрет webhook не вставляйте в сообщения, документацию или Git. Удобнее выполнить запрос локально из PowerShell, сохранив значения только во временных переменных текущего окна.

Проверка после подключения:

1. Откройте `<PUBLIC_BASE_URL>/health` — должен появиться ответ с `"ok": true`.
2. Напишите боту `/start`, затем отправьте обычный текст.
3. Выполните `/notes` и откройте сохранённую запись.
4. Выполните `/site` и перейдите по временной кнопке.
5. Проверьте ссылку, изображение, файл, `/ask`, изменение, скрытие и удаление.

## Резервная копия

Исходная `notes.db` уже является локальной резервной копией старой версии. Облачную D1 можно выгрузить так:

```powershell
npx wrangler d1 export DB --remote --output=.data/fastnotes-backup.sql
```

Файл резервной копии содержит личные данные и исключён из Git. В D1 сохраняются только описания и Telegram `file_id`: отдельной резервной копии байтов вложений в этой версии нет.

## Важные ограничения первой версии

- доступ имеют только владелец и преподаватель `126041348`; каждый работает в отдельном пространстве заметок;
- для обычных документов сохраняются описание и Telegram `file_id`, но содержимое не анализируется;
- если Telegram перестанет выдавать файл по сохранённому `file_id`, заметка и её описание останутся, но скачать файл с сайта не получится;
- реальные сквозные тесты RAG и карточек требуют созданного индекса Upstash, TMDB Read Access Token и действующего Telegram-бота;
- если Upstash временно недоступен, ответы продолжают искать источники через D1 FTS5;
- данные TMDB по условиям сервиса следует обновлять или удалять не позднее чем через шесть месяцев; автоматический фоновый обход намеренно не добавлен.
